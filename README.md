# MapTools

**Version 1.1** · © 2026 Jimmy Paul · voir `LICENCE.txt`

Cartographie interactive des groupes, sous-groupes, utilisateurs, rôles et partages d'un annuaire Entra ID ou Active Directory, avec le statut d'activité des comptes, un rapport décisionnel et le suivi avant / après d'une remédiation. Fonctionne hors ligne dans Edge ou Chrome ; aucune donnée ne quitte le poste.
